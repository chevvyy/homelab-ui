Homelab Control Plane: 4-Week Roadmap
Oct 7, 2026 ·  @Dev How
Scope
In 28 days you ship a web app, running inside k3s, that watches your cluster, Proxmox and
TrueNAS live and deploys, links, exposes and deletes apps from three sources (weeks 1–
2), then wrap it as a desktop app and an iPhone app (weeks 3–4). Plan on roughly 3
focused hours a day; if you have less, stretch each week rather than cutting the Definition
of Done.
In scope (must ship)
Live views of k3s workloads, Proxmox nodes/VMs/LXCs and TrueNAS
pools/datasets/alerts, updating without refresh
Deploy from a pasted YAML, a container image reference, or a GitHub repo URL
Create, update, restart, scale, roll back and delete deployments, with errors explained
in plain language
One toggle per app: Internal (Tailscale only), Public (howellsas.com via Cloudflare
Tunnel), or Off
Link app A to app B so A gets B's in-cluster address injected automatically
One sign-in to the wrapper; the backend holds every system credential, so switching
systems is a sidebar click
Out of scope (Rancher does this, you don't need it)
Multiple users, RBAC, teams and projects
Cluster provisioning, node upgrades, Helm catalog browsing
Creating or editing Proxmox VMs and TrueNAS pools (read and basic power/snapshot
actions only)
Monitoring stack and long-term metrics history

systems, and pushes changes to the browser over one WebSocket. The cluster stays the
source of truth: every object the wrapper creates carries its labels, so nothing is lost if the

Key design decisions
1. App = a label, not a CRD. Everything for an app gets 
homelab.io/app=<name>
 and
homelab.io/managed=true
. The original source (YAML, image or repo + commit) is
saved in an annotation. A CRD + controller is the week-3 upgrade.
2. Exposure = which Traefik entrypoint and hostname. Internal apps get
<app>.lan.howellsas.com
 on a Tailscale-only entrypoint. Public apps get
<app>.howellsas.com
; a wildcard Cloudflare Tunnel route sends 
*.howellsas.com
 to
Traefik, so switching is one IngressRoute patch plus one Cloudflare DNS record.
3. Linking = injected env vars. Linking A to B adds 
B_URL=http://b.
<ns>.svc.cluster.local:<port>
 to A and rolls A. Optional: a NetworkPolicy that
allows only linked traffic.
4. One sign-in. You log into the wrapper once (password + session cookie, or Tailscale
identity headers via 
tailscale serve
). Proxmox, TrueNAS and k8s credentials live
server-side, encrypted in SQLite, so the browser never handles them.
5. Storage defaults to TrueNAS. Generated PVCs use your democratic-csi StorageClass
unless the user picks node-local.
Open question: does the Caddy VPS path (used for Jellyfin) become a third exposure
mode, or stay manual? The plan treats it as a stretch goal.

App risks
Internal HTTPS: the app's webview needs a valid certificate for your internal hostname.

can wrap the same 
web/

Traefik entrypoints and TLS (day 10) take the longest to debug. Set up the two
entrypoints and a wildcard cert by hand on day 7 or 8, before the UI depends on them.
